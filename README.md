\# Sistema de Punto de Venta - Refaccionaria Automotriz “El Águila”



\## Descripción general



Este proyecto consiste en un sistema de punto de venta desarrollado para la Refaccionaria Automotriz “El Águila”. 



Su objetivo principal es automatizar el registro de ventas, el control de inventario, la gestión de productos, proveedores y usuarios, así como la consulta de reportes básicos del negocio.



El sistema permite mejorar la organización de la información, reducir errores en los registros manuales y facilitar la toma de decisiones mediante el uso de herramientas tecnológicas.



\## Tecnologías utilizadas



\- Java

\- Java Swing

\- MARIADB

\- HeidiSQL

\- NetBeans

\- Git

\- GitHub



\## Instrucciones de instalación y ejecución

Abrir el proyecto en NetBeans.
Importar o crear la base de datos correspondiente en HeidiSQL.
Verificar la conexión a la base de datos dentro del código del proyecto.
Ejecutar el sistema desde NetBeans, iniciando desde la clase principal del proyecto.
